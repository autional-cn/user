# Autional 用户中心

**域名**：[user.autional.cn](https://user.autional.cn)
**技术栈**：Vite + React 19 + TypeScript + Tailwind CSS
**仓库**：[github.com/autional-cn/user](https://github.com/autional-cn/user)

个人资料、安全设置、会话与授权管理。

## 开发

```bash
pnpm install
pnpm dev      # http://localhost:13104
pnpm build    # 构建产物：apps/end-user-portal/dist/
pnpm test     # Vitest 单元测试
```

## 部署

推送至 `main` 分支后由 Vercel 自动部署。
